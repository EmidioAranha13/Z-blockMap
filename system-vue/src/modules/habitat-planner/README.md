# Habitat Planner

Guia relacional entre Pokémon e itens da Pokopia (habitats, climas, especialidades).

A tela consulta a Pokopia API em `/api/v1` (proxy Vite para `https://pokopiapi.com`).
A coleta fica em `src/apis/`.
