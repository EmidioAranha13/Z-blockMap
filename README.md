# Z-blockMap

Repositório com dois sistemas:

| Pasta | O que é |
|---|---|
| `system-vue/` | Editor web (Vue 3 + Vite + Canvas) |
| `system-react-native/` | App mobile (em preparação) |

## Editor web

```bash
cd system-vue
npm install
npm run dev
```

Abre em `http://localhost:5173`. Detalhes de uso estão no `system-vue/README.md`.
